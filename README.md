# Site Institucional – Landing Page

Projeto de um **site institucional responsivo**, desenvolvido com **HTML, CSS e JavaScript**, simulando uma página de apresentação de curso/empresa com chamada para ação, seção institucional, FAQ, depoimentos e modal de cadastro.

---

## Sobre o projeto

Este projeto foi desenvolvido com foco em:

- Estruturação semântica em HTML
- Estilização moderna e responsiva com CSS
- Interações simples com JavaScript puro (Vanilla JS)

O layout simula uma **landing page institucional**, comum em sites de cursos, empresas e produtos digitais.

---

## Funcionalidades implementadas

- Header fixo com botão de chamada para ação
- Modal de cadastro com `<dialog>`
- Botões interativos
- Layout responsivo para desktop, tablet e mobile

---

## Tecnologias utilizadas

### HTML

- HTML5 semântico

### CSS

- CSS moderno com:
  - Variáveis (`:root`)
  - Flexbox
  - Media Queries
  - `position: fixed` e `position: sticky`
  - Responsividade com `clamp()`
- Organização de estilos em arquivos separados:
  - `globalStyle.css`
  - `index.css`
- Fonte externa via Google Fonts (Inter e Roboto)

### JavaScript

- JavaScript puro (Vanilla JS)
- Manipulação do DOM
- Controle de abertura e fechamento de modal
- Uso de `addEventListener`
- Uso de `classList`
